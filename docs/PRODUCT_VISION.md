# RadioApp – Product Vision

## Vision
RadioApp ska göra Google Nest Hub till en modern, fristående Sveriges Radio-radio.

Nest Hub är den centrala upplevelsen. Användaren ska kunna se kanaler, se vad som spelas, byta kanal och använda touch utan att behöva hålla telefonappen öppen.

## Primära mål
- Officiella Sveriges Radio-liveströmmar.
- Rik Nest Hub-upplevelse.
- Kanal, program, bild och LIVE-status.
- Kanalbläddring och favoriter på stödda smarta displayer.
- Nationella och lokala P4-kanaler.
- Ingen obligatorisk egen backend, användarinloggning eller ljudproxy.
- Cast-enheten hämtar ljudströmmen direkt från SR.

## Produktdelar
### Nest Hub / Cast Receiver
Primär radioyta: Now Playing, kanalval, favoriter, programinformation och touch där plattformen stödjer det.

### Android
Setup, Cast sender, fjärrkontroll, favoriter och inställningar.

### Sveriges Radio
Officiella ljudströmmar används för playback. SR:s API kan användas för metadata men får aldrig vara ett krav för ljud.

## Icke-mål
- Ingen gammal Assistant Conversational Action.
- Ingen streamingproxy.
- Ingen cloud sync i första versionen.
- Ingen kopia av SR:s officiella app.
- Ingen påstådd Hub-funktion utan riktig device-test.
