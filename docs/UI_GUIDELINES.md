# RadioApp – UI Guidelines

## Känsla
Modern digital bordradio, inte ett tekniskt Cast-verktyg.

## Principer
- Kanal först
- Stora touchytor
- Snabbt kanalbyte
- Tydlig LIVE-status
- Minimal text under playback
- Programbild när den hjälper
- Fungerar utan metadata
- Ljust tema som första riktning

## Nest Hub
Prioritera Now Playing, Favoriter, Kanaler och lokala P4-kanaler. UI ska vara läsbart på avstånd.

## Android
Top bar med RadioApp + Cast-knapp, Spelas nu, Favoriter och Kanaler. Följ Google Cast UX och använd inte egen device picker om standardkomponenten löser behovet.

## Branding
Skapa egen identitet. Kopiera inte SR:s officiella app eller branding på ett sätt som kan skapa förväxling.
